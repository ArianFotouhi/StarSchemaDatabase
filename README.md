# StarSchemaDatabase

**StarSchemaDatabase** is a modular architecture for implementing a Star Schema database, complete with a server interface for creating tables, inserting data, and fetching results. This project provides a clean and scalable approach to working with dimensional data models commonly used in data warehousing.

## ✨ Features

- Modular and extensible Star Schema design
- Server interface for interacting with the database
- Support for creating tables programmatically
- APIs to insert and retrieve data
- Designed for analytics and reporting use cases
